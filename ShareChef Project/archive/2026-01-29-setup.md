# Gemini Live Voice Assistant Integration

## What This Does

This integration adds a **full conversational AI voice assistant** to your ShareChef app, similar to ChatGPT's Advanced Voice Mode or Google's Gemini Live. Users can:

- Have natural, human-like conversations about cooking
- Ask for recipe suggestions by talking
- Get real-time cooking guidance
- Interrupt the assistant naturally
- Have continuous back-and-forth conversations

## Features

✅ Real-time bidirectional audio streaming via WebSocket
✅ Natural interruptions and turn-taking
✅ High-quality AI voice synthesis (multiple voice options)
✅ Automatic speech recognition
✅ Conversation history display
✅ Beautiful, responsive UI
✅ Error handling and reconnection logic

## Files Included

1. **`gemini-live.ts`** - Core WebSocket integration with Gemini Live API
2. **`VoiceAssistant.tsx`** - React component with full UI
3. **`SETUP.md`** - This file

✅ You already did this step!

### Step 3: Add Route to Your App

Open `src/App.tsx` (or wherever your routes are) and add:

```tsx
import VoiceAssistant from './pages/VoiceAssistant';

// In your routes:
<Route path="/voice" element={<VoiceAssistant />} />
```

### Step 4: Add Navigation Link

In your main navigation (probably in `src/App.tsx` or a `Nav` component), add:

```tsx
<Link to="/voice">🎙️ Voice Assistant</Link>
```

### Step 5: Start Your Dev Server

```bash
cd /Users/taibenor/Documents/sharechef
npm run dev
```

### Step 6: Test It!

1. Go to `http://localhost:5173/voice` (or whatever port Vite uses)
2. Click "Start Voice Chat"
3. Allow microphone access when prompted
4. Start talking! Try: "Hey, I have chicken and rice. What should I make?"

## Customization Options

### Change the Voice

In `VoiceAssistant.tsx`, find the `voiceName` setting and change it:

```tsx
voiceConfig: {
    voiceName: 'Puck' // Options: Puck, Charon, Kore, Fenrir, Aoede
}
```

**Voice Personalities:**
- **Puck** - Friendly and upbeat (default)
- **Charon** - Calm and authoritative
- **Kore** - Warm and nurturing
- **Fenrir** - Energetic and confident
- **Aoede** - Gentle and soothing

### Customize the System Prompt

Edit the `systemInstruction` in `VoiceAssistant.tsx` to change the assistant's personality, capabilities, or focus.

### Styling

The component uses Tailwind CSS. Modify the classes in `VoiceAssistant.tsx` to match your app's design.

## Troubleshooting

### "Please add your Gemini API key"
- Make sure `.env.local` has `VITE_GEMINI_API_KEY=...`
- Restart your dev server (`npm run dev`)

### "Failed to start voice assistant"
- Check browser console for detailed errors
- Make sure you're using HTTPS or localhost (microphone requires secure context)
- Verify your Gemini API key is valid

### No audio playing
- Check your browser's audio permissions
- Make sure your speakers/headphones are working
- Check browser console for audio errors

### Connection keeps dropping
- Check your internet connection
- Verify API key hasn't expired or hit rate limits
- Look for WebSocket errors in browser console
